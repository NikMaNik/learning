# Learning English

TUI-приложение для изучения английского языка с повторением по алгоритму [[SM2]] и REST API.

## Быстрый старт

```bash
cargo run
```

Запускает:
- TUI в терминале (ratatui)
- REST API на `localhost:3000` (axum)
- SQLite базу `words.db`

## Навигация (клавиатура)

| Клавиша | Действие |
|---------|----------|
| `1` | REVIEW — повторение слов по расписанию (SM-2) |
| `2` | ADD — добавить слово |
| `3` | UPDATE — обновить слово (с поиском) |
| `4` | IMPORT — импорт из .md файла |
| `5` | DEL — удалить слово |
| `6` | FORGOT — повторение забытых слов (quality < 3) |
| `7` | UPCOMING — список слов на ближайшие N дней (слово + перевод) |
| `q` | Выход |

## Повторение «забытых» и списки

- **FORGOT** (`6`) — повторение только тех слов, которые ты не запомнил (последняя оценка `quality < 3`).
- **UPCOMING** (`7`) — скроллируемый список `слово — перевод` для слов, чьё `next_review` наступает в ближайшие N дней (N изменяемое, по умолчанию 2).
