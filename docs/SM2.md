# SM-2 + Левенштейн

## SM-2 Алгоритм

Повторение с интервалами (Spaced Repetition).

### Quality (0-5)

| Quality | Описание |
|---------|----------|
| 0 | забыл |
| 1 | неправильно, вспомнил после ответа |
| 2 | неправильно, но легко вспомнил |
| 3 | правильно с трудом |
| 4 | правильно с небольшими сомнениями |
| 5 | идеально |

### Формула интервалов

```
reps=0 → reps=1: interval = 1
reps=1 → reps=2: interval = 6
reps>1:          interval = interval × EF

EF = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))
EF ≥ 1.3
```

### Таблица интервалов (пример)

| Reps | Interval | EF |
|------|----------|-----|
| 0→1 | 1 день | 2.5 |
| 1→2 | 6 дней | 2.6 |
| 2→3 | 15 дней | 2.7 |
| 3→4 | 41 день | 2.8 |

## Расстояние Левенштейна

Используется для **автоматической оценки** ответа (без ручного ввода quality).

### Маппинг distance → quality

| Нормализованное расстояние | Quality |
|---------------------------|---------|
| 0.0 (точное совпадение) | 5 |
| < 0.2 | 4 |
| < 0.4 | 3 |
| < 0.6 | 2 |
| < 0.8 | 1 |
| ≥ 0.8 | 0 |

Формула: `distance / len(correct_answer)`

### Примеры

| Ответ | Правильно | Distance | Quality |
|-------|-----------|----------|---------|
| яблоко | яблоко | 0 | 5 |
| яблок | яблоко | 1 | 4 |
| яблак | яблоко | 2 | 3 |
| апельсин | яблоко | 7 | 0 |
