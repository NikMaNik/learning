# Фичи

## CRUD операции

- **REVIEW** (`1`) — повторение по расписанию [[SM2]]
- **ADD** (`2`) — добавление слова english→russian
- **UPDATE** (`3`) — поиск → редактирование
- **IMPORT** (`4`) — импорт из .md файла
- **DEL** (`5`) — удаление с подтверждением
- **FORGOT** (`6`) — повторение забытых слов
- **UPCOMING** (`7`) — список слов на ближайшие N дней

## Review (Повторение)

- Автоматическая оценка через **расстояние Левенштейна** (без ручного ввода)
- Маппинг расстояния → quality (0-5)
- Показывает: ✓/✗, quality, расстояние, следующее повторение
- При ошибке — показывает правильный ответ

## Forgot (Повторение забытых)

- Повторяет только слова, которые ты **не запомнил** на последней сессии (последняя оценка `quality < 3`)
- Тот же ввод/оценка, что и в обычном REVIEW
- Отслеживается через колонку `last_quality` (записывается при каждом ревью)
- В главном меню и статус-баре показывается счётчик забытых слов

## Upcoming (Слова на ближайшие N дней)

- Скроллируемый список `слово — перевод` (j/k/↑/↓)
- Показывает слова, у которых `next_review` наступает в ближайшие **N** дней (включая уже просроченные)
- **N** изменяемое: введи число дней в поле и нажми **Enter** (по умолчанию 2)
- Удобно для самостоятельной подготовки: видно слово и его перевод

## Поиск (UPDATE)

- Ввод слова → поиск по базе
- **Точное совпадение** → сразу редактирование
- **Похожие слова** → список для выбора (алгоритм схожести)

## Пробелы

- При добавлении/обновлении: пробелы сохраняются (`"привет мир"` → `"привет мир"`)
- При сравнении (review): пробелы игнорируются (`"ты вы"` = `"тывы"`)

## Дедупликация

- Проверка на дубликаты при добавлении (по english и russian, без учёта регистра)

## Терминал

- Тёмная тема (чёрный фон, белый текст)
- Фиксированный размер (80×24)
- Корректная очистка при выходе (`ratatui::restore()` + `Clear(All)`)
